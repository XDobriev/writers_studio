# QA: страница персонажей — правая панель + группировка

Проверить после деплоя на https://avtorskaya-studiya.vercel.app

---

## 1. Правая панель «Связи»

- [ ] Панель видна при открытой странице `/books/:id/characters`
- [ ] При выборе персонажа без связей — надпись «Связей пока нет.»
- [ ] При выборе персонажа со связями — список карточек в панели
- [ ] Кнопка «Добавить связь» открывает inline-форму внутри панели
- [ ] Добавление связи сохраняется и сразу отображается в панели
- [ ] Редактирование ярлыка связи (debounce) сохраняется
- [ ] Удаление связи (×) работает
- [ ] При смене активного персонажа список связей обновляется
- [ ] Когда персонаж не выбран — надпись «Выберите персонажа»

---

## 2. Группировка в сайдбаре (фильтр «все»)

- [ ] Видны секции: ГЛАВНЫЕ, ВТОРОСТЕПЕННЫЕ, ЭПИЗОДИЧЕСКИЕ
- [ ] Рядом с заголовком группы отображается правильное число персонажей
- [ ] Клик на заголовок сворачивает секцию (chevron поворачивается)
- [ ] Повторный клик разворачивает секцию обратно
- [ ] Пустые группы не отображаются
- [ ] Поиск по имени работает внутри группировки (группы с 0 результатами скрываются)
- [ ] При нулевых результатах поиска — надпись «Ничего не найдено»

---

## 3. Фильтры по роли

- [ ] Фильтры «главные» / «второстеп.» / «эпиз.» показывают плоский список без заголовков групп
- [ ] После смены фильтра — правильная выборка персонажей
- [ ] Возврат к «все» восстанавливает группировку

---

## 4. Адаптив (мобайл < 768px)

- [ ] Правая панель скрыта на мобайле
- [ ] Список персонажей и просмотр карточки переключаются как прежде
- [ ] Кнопка «←» возвращает к списку

---

## 5. Общая работоспособность

- [ ] Создание нового персонажа — появляется в нужной группе, становится активным
- [ ] Удаление персонажа — исчезает из группы, связи очищаются
- [ ] Автосейв полей (Внешность, Характер, Предыстория, Авторские заметки) работает
- [ ] Загрузка аватара — отображается в элементе списка и в карточке связи
- [ ] Нет горизонтального скролла на десктопе при стандартном размере окна
