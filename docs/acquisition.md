## Конкретные площадки

### 🔴 Горячие (писатели активно ищут инструменты)

**Author.Today** ([author.today](https://author.today))
- Крупнейший русскоязычный самиздат, ~500k авторов
- Форум → раздел «Рабочий стол» / «Инструменты»
- Подход: ответить на чужой вопрос развёрнуто → в конце упомянуть студию
- Не постить холодную рекламу — забанят

**Telegram-чаты писателей**
- Искать через [tgstat.ru](https://tgstat.ru) по словам: «писатели», «авторы», «фэнтези авторы», «самиздат», «литературная мастерская», «NaNoWriMo»
- Алгоритм: зайти → читать 2–3 дня → ответить полезно без продукта → потом пост или DM

Шаблон поста в чат:
> Привет. Я сделал редактор специально для длинной прозы — с персонажами, хронологией и картой мира в одном проекте. Не Scrivener (страшный), не Notion (для всего). Ищу первых авторов, которые попробуют и скажут честно, чего не хватает.
>
> Бесплатно, сейчас открытая бета: avtorstudio.com

**Ficbook** ([ficbook.net](https://ficbook.net))
- Фанфикшн, длинные тексты, главы, активная аудитория
- Форум и группы ВКонтакте при сайте
- Аудитория моложе, лояльна к indie-инструментам

### 🟡 Тёплые (нужно найти)

**ВКонтакте — группы писателей**
- Поиск по группам: «писатели», «авторы», «литературная мастерская», «фэнтези авторы»
- Не постить в стену без разрешения — написать администратору лично
- Предложить: промокод на Pro для участников, честный обзор без рекламного давления

**Небольшие Telegram-каналы (500–5000 подписчиков)**
- Авторы таких каналов читают DM, у них нет PR-менеджера
- Предложить: пожизненный Pro-доступ + промокод для 5 подписчиков

Шаблон DM автору канала:
> Привет, читаю ваш канал — нравится, как вы пишете про структуру текста. Я сделал редактор специально для авторов длинной прозы, называется Авторская студия. Хотел бы показать вам — не как рекламу, а как инструмент для честного разбора. Дам полный доступ бесплатно. Если понравится — расскажете, если нет — тоже ок.

**Pikabu** — теги #писатели #авторы
- Формат: длинный личный пост с историей создания + скриншоты + ссылка в конце
- Если зайдёт — сотни переходов за день

## Советы по не-техническим задачам

### Email-захват (форма на лендинге)
Самая высокодоходная задача до анонса. Один `<input>`, одна кнопка, Edge Function → таблица `waitlist`.
Без формы весь трафик с анонсов уходит без следа. **Сделать перед первым постом в сообществах.**

### Социальное доказательство
- Не делать ничего, пока нет реальных пользователей — фейк чувствуется
- После первых 10 активных: написать лично, попросить одну фразу («что изменилось»)
- Одна честная цитата с именем > трёх анонимных

### Sticky nav на лендинге
- Сейчас nav исчезает при скролле — CTA недоступна в середине страницы
- Исправить одним проходом вместе с §18–21
