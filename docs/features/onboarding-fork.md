# Онбординг-развилка и создание книги (G-7 v2)

## 1. Контекст и проблема

В предыдущей итерации задачи G-7 возникло архитектурное и пользовательское расхождение:
1. **Два конфликтующих окна создания**:
   - В `src/pages/Home.tsx` при `books.length === 0` открывалась развилка `OnboardingForkModal`, а при наличии хотя бы одной книги (`books.length > 0`) кнопка «+ Создать книгу» вызывала старую форму `showCreate`.
2. **Непрофессиональное представление структуры**:
   - На Шаге 2 развилки предлагались «Трёхактная структура (7 глав)» и «Путь героя (9 глав)». Приравнивание драматических битов к фиксированным главам воспринимается авторами как дилетантский подход (в романе 25–45 глав, а не 7).
3. **Потеря ключевого функционала книги**:
   - Шаг 2 развилки не содержал выбора обложки (градиенты и загрузка арта), жанров (включая авторский ввод через «Другое») и общей цели по объёму романа.

## 2. Архитектурные решения

### Решение 1. Единая точка входа
Кнопка **«+ Создать книгу»** в `Home.tsx` всегда открывает `OnboardingForkModal`. Старая форма `showCreate` упраздняется.

### Решение 2. Шаг 1 — Развилка стратегии старта
Содержит 3 равноправные карточки:
1. **Импортировать готовую рукопись** (`.docx`, `.txt`, `.md`) — закрывает развилку и вызывает `ImportManuscriptModal`.
2. **Начать новую книгу** — переходит на Шаг 2 настройки книги.
3. **Изучить студию на примере романа** — клонирует демо-роман «Город, которого нет» (10 глав, персонажи, локации, хронология) без расхода бесплатного лимита.

### Решение 3. Шаг 2 — Полноценный паспорт книги
Если выбрано «Начать новую книгу», автор попадает на понятный экран создания:
- **Название книги** (обязательное поле).
- **Жанры**: компонент `GenrePicker` (17 предустановленных жанров + кнопка «Другое» для свободного ввода, например: *«Остросюжетный боевик с элементами фантастики»*).
- **Литературная форма и цель**:
  - 📖 *Роман* — по умолчанию цель **70 000 слов**.
  - 📜 *Повесть* — по умолчанию цель **30 000 слов**.
  - 📝 *Рассказ* — по умолчанию цель **5 000 слов**.
  - ✍️ *Свободный объём* — без цели (0).
  *(Автор может вручную скорректировать предложенное число слов).*
- **Обложка**: компонент `CoverPicker` (12 цветовых палитр + загрузка собственного изображения с диска/камеры).
- **Продолжение серии**: компонент `SeriesTransferPicker` (отображается только если у автора уже есть книги в аккаунте).

### Решение 4. Вынос драматургических структур в раздел «Структура» (Отдельная задача)
Драматургические схемы (*Save the Cat! Writes a Novel*, *7-точечная структура*, *Путь героя*) отделяются от создания книги и выносятся в раздел **«Структура»** (`/books/:id/outline`) и **«Замысел»** (`/books/:id/plan`). Там они будут оформлены в виде карточек сцен и ориентиров для планирования сюжета.
