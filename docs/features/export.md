# Feature: Экспорт

**Маршрут:** `/books/:id/export`

## Компоненты

- `src/pages/Export.tsx` — UI + логика конвертации.

## Функции

- Форматы: HTML, TXT, Markdown (без внешних зависимостей).
- Собственные конвертеры HTML→TXT и HTML→Markdown.
- Тогглы: «только готовые главы», «заголовки глав внутри документа».
- Скачивание через Blob + `a[download]`.

## Следующий шаг

DOCX через docx.js, EPUB через epub.js — отдельный заход с библиотеками.
