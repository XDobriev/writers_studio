~~**Баг #9 — Карточка книги ломается на mobile: текст в футере сливается**~~

## Запланированные фичи

~~**Адаптивный grid карточек книг**~~
~~На desktop карточки выстраиваются по одной слева — пустота на 67% ширины.~~ — закрыто вместе с Багом #9.

**Email в хедере на мобайле**
На 375px email занимает половину хедера. Скрыть на `width < 640px`, оставить только кнопку «Выйти».

**Прогресс-бар при 0% невидим**
Трек бара почти совпадает с фоном карточки — нужен явный цвет трека даже при нуле прогресса.

**Обложка книги**
Supabase Storage bucket `book-covers`, путь `{user_id}/{book_id}.jpg`. Колонка `cover_url text` в `books`. UI: загрузка при создании + кнопка «Изменить обложку» на дэшборде. Ресайз/кроп на клиенте (canvas), max 1MB. Карточка на полке показывает обложку вместо градиента.
