**Обложка книги**
Supabase Storage bucket `book-covers`, путь `{user_id}/{book_id}.jpg`. Колонка `cover_url text` в `books`. UI: загрузка при создании + кнопка «Изменить обложку» на дэшборде. Ресайз/кроп на клиенте (canvas), max 1MB. Карточка на полке показывает обложку вместо градиента.
