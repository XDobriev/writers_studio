## Запланированные фичи

**Управление подпиской**
Раздел в настройках пользователя (модалка ⚙). Показывает текущий план, историю платежей, кнопку апгрейда. Требует проработки тиров (Free / Pro / Lifetime), платёжного провайдера и логики разблокировки функций по плану. Связано с разделом «Монетизация» в roadmap.md.

**Проверка орфографии**
Сейчас в редакторе работает браузерная проверка (`spellcheck=true` на contenteditable TipTap). Достаточно для большинства пользователей. При необходимости — TipTap-расширение + LanguageTool API (платный при нагрузке). См. Backlog в roadmap.md.

**Обложка книги**
Supabase Storage bucket `book-covers`, путь `{user_id}/{book_id}.jpg`. Колонка `cover_url text` в `books`. UI: загрузка при создании + кнопка «Изменить обложку» на дэшборде. Ресайз/кроп на клиенте (canvas), max 1MB. Карточка на полке показывает обложку вместо градиента.
