# Email-онбординг — Blueprint

_Зафиксировано: 2026-05-27. Реализовывать после подключения ЮKassa (roadmap §2)._

## Стек

- **Resend** — провайдер (бесплатно до 3 000 писем/мес, легко интегрируется с Supabase)
- **Supabase Edge Function** `send-onboarding-email` — вызывается по триггеру или через `pg_cron`
- Логика: каждый день проверять `profiles.created_at`, отправлять нужное письмо по дню

## Aha moment

Написаны первые слова в первой главе.

Воронка:
```
Регистрация → Создал книгу → Открыл главу → Написал абзац (AHA)
```

### Email 4 — Персонажи (день 5)

**Тема:** Как не потерять, кто есть кто
**Preview:** Привяжите героя к главе — он появится в её обзоре.

---

Большинство авторов ведут картотеку персонажей в отдельном документе. Потом забывают его открыть.

В студии персонажи живут рядом с рукописью.

Откройте раздел «Персонажи» в вашей книге:
1. Создайте карточку героя — имя, роль, описание
2. Привяжите к главе, где он появляется
3. При открытии главы — персонаж виден на панели

Работает и для второстепенных, и для тех, кто появляется только в одной сцене.

**[Попробовать персонажей →](https://avtorstudio.com/books)**

## Техническая реализация (когда придёт время)

1. Зарегистрироваться на [resend.com](https://resend.com), получить API-ключ
2. Добавить `RESEND_API_KEY` в Supabase Secrets
3. Создать Edge Function `send-onboarding-email`
4. Supabase `pg_cron`: каждый день в 10:00 → проверить `profiles` → отправить нужное письмо
5. Добавить поле `last_onboarding_email int default 0` в `profiles`
