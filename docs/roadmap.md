## Приоритет 5 — обложка книги

Supabase Storage bucket `book-covers`, путь `{user_id}/{book_id}.jpg`. Колонка `cover_url text` в `books`. UI: загрузка при создании + кнопка «Изменить обложку» на дэшборде. Ресайз/кроп на клиенте (canvas), max 1 MB. Карточка на полке показывает обложку вместо градиента.

## Продвижение и первые пользователи

### Критерии готовности к продвижению

Не запускать рекламу до выполнения всех пунктов:

- [ ] Весь путь нового пользователя пройден без подсказок (регистрация → книга → глава → сохранение → возврат)
- [ ] Нет критичных потерь данных или сломанного входа
- [ ] Есть канал обратной связи (Telegram-чат или почта) и готовность отвечать

### Фазы выхода к аудитории

**Фаза 0 — ручное тестирование (сейчас)**
- Дать попробовать 2–3 знакомым авторам без объяснений
- Собрать: что непонятно, где зависло, чего не хватает
- Цель: убедиться, что замкнутый цикл работает без поддержки

**Фаза 1 — первые 20–50 пользователей (ранние последователи)**
- Создать Telegram-чат (не канал): «Авторская студия | бета» — место для обратной связи
- Вручную написать в тематические обсуждения: LiveLib, ВКонтакте-группы авторов, Пикабу
- Формат: честно, без рекламного тона — «делаю инструмент, ищу авторов потестировать»
- Цель: живые отзывы, понять что ломается у реальных людей

**Фаза 2 — рост до 100–300 пользователей**
- Пост на Хабре / vc.ru / Пикабу: «Я сделал русский Scrivener в браузере»
- Telegram-канал с обновлениями (changelog, скриншоты, истории пользователей)
- Платная реклама на LiveLib — только когда есть скриншоты и отзывы
- SEO: статические страницы «как написать книгу», «структура романа» и т.д.

**Фаза 3 — монетизация**
- Не раньше 100–300 активных бесплатных пользователей (см. раздел ниже)

### Что НЕ делать раньше времени

- Не запускать платную рекламу без отзывов — конверсия будет нулевой
- Не делать канал в Telegram пока не о чем вещать — сначала чат
- Не покупать домен до первых признаков роста

## Монетизация и инфраструктура

_Исследование рынка: май 2026._

### Позиционирование

«Первый русскоязычный Scrivener в браузере» — ниша практически свободна. Прямых русскоязычных конкурентов нет. Иностранные аналоги (NovelCrafter, Campfire, World Anvil) без локализации и рублёвых цен.

### Модель монетизации

| Тир | Цена | Что включает |
|---|---|---|
| Free | 0 ₽ | 1 книга, базовый редактор, ~20 персонажей, без экспорта |
| Pro | 290–390 ₽/мес или ~2 900 ₽/год | Безлимит проектов, все функции, экспорт |
| Lifetime | 2 490–3 490 ₽ | Всё навсегда, разовая оплата |

Lifetime важен для RU-рынка — многие не доверяют подпискам у небольших сервисов.

**Когда запускать монетизацию:** не раньше 100–300 активных бесплатных пользователей.

### Домен

Купить при первых признаках роста аудитории. `.ru` (~400 ₽/год) или `.com` (~1 000 ₽/год). Подключить к Vercel через CNAME. `.vercel.app` не подходит для платного продукта.

### Хостинг

| Этап | Решение |
|---|---|
| Сейчас | Vercel Hobby (бесплатно) |
| Первые 10–20 платящих | Vercel Pro ($20/мес) — нельзя допускать даунтайм для платных пользователей |
| Рост RU-аудитории / жалобы на доступность | Timeweb Cloud App Platform (авто-деплой из GitHub, ЦОДы в РФ) |
| Требование ФЗ-152 | VPS в РФ (Beget, Timeweb, Selectel) |

Supabase остаётся в любом сценарии — Beget/Timeweb хостят только фронтенд и не заменяют Auth/Postgres/Realtime.

### Главный риск

Русскоязычная аудитория не привыкла платить за writing tools. Нужен агрессивный free tier для набора базы, и только потом конвертация в платных.
