## ФАЗА 2 — Июнь–Июль: рост и дифференциация

Фичи, которые отличают продукт от Google Docs и дают основание платить.

### Соавторство (ключевая фича)

Реализовывать поэтапно, не всё сразу.

- [ ] **Уровень 1 — Публичная ссылка (read-only)** — генерировать `share_token` для книги → страница `/share/{token}` без авторизации. Подходит для «показать редактору/агенту». Миграция: колонка `share_token uuid` в `books`.
- [ ] **Уровень 2 — Приглашение соавтора** — новая таблица `book_collaborators (book_id, user_id, role: editor|viewer, invited_by, created_at)`. Владелец вводит email → создаётся pending-запись → по email-ссылке коллаборатор принимает. RLS обновить: `auth.uid() = user_id OR EXISTS (SELECT 1 FROM book_collaborators WHERE book_id = ... AND user_id = auth.uid())`. Это 80% ценности соавторства без сложной инфраструктуры.
- [ ] **Уровень 3 — Real-time (после 100 платящих)** — Y.js + TipTap Collaboration extension + Supabase Realtime или Hocuspocus WebSocket сервер (Fly.io/Timeweb). TipTap v3 поддерживает Y.js нативно. Реализовывать не раньше наличия платящих пользователей.

### Монетизация-инфраструктура

- [ ] **ЮKassa** — основной платёжный провайдер для РФ. Поддерживает самозанятых (4% налог с физлиц, 6% с юрлиц, лимит 2,4 млн ₽/год — достаточно на старте). При превышении лимита — переходить на ИП УСН 6%. Edge Function для вебхуков ЮKassa → обновление `plan` пользователя.
- [ ] **Управление подпиской** — модалка в SettingsModal: текущий план, кнопка апгрейда, история платежей. Сейчас кнопка «Управление» disabled.
- [ ] **Lifetime deal (при запуске)** — продать 50–100 Lifetime за 1990 ₽ в момент публичного анонса. Быстрые деньги + лояльные беталисты. Платформа: пост на Хабре / ProductHunt или просто Telegram-канал.

### Визуализация (backlog → приоритет)

- [ ] **Графическая карта мира** — рендер локаций по координатам `x/y` из `locations` (canvas или SVG, drag для перемещения).
- [ ] **Горизонтальная timeline** — события по полю `pos` из `timeline_events` в виде горизонтальной ленты.

### Экспорт расширенный

- [ ] **DOCX** — через `docx.js`. Титульная страница (название, автор, жанр), автоматическое оглавление, разделители глав. Опционально: список персонажей как приложение в конце.
- [ ] **EPUB** — через `epub-gen` или `foliant`. Метаданные, обложка (placeholder-изображение), оглавление, корректные разрывы глав.
- [ ] **FB2** — формат популярен в РФ (Litres, FB Reader). Структура: `<FictionBook>` + `<body>` с `<section>` на главу. Можно сгенерировать вручную без библиотек.

## ФАЗА 3 — После первых платящих: масштаб

- [ ] **Аналитика онбординга** — перенести флаг завершения онбординга из `localStorage` в `profiles.onboarded_at timestamp`. Даст данные: сколько пользователей завершили онбординг vs нажали «Посмотрю позже». Требует миграцию + обновление RLS. Актуально при 50+ пользователях.
- [ ] **Admin: графики роста** — DAU/WAU/MAU во времени (линейный график), а не только текущие цифры.
- [ ] **Admin: retention** — % пользователей, вернувшихся через 7 и 30 дней.
- [ ] **Admin: топ пользователей** — топ-10 по словам и по активности.
- [ ] **Admin: аномалии** — пользователи без книг, без активности 60+ дней (для понимания churn).
- [ ] **Мобильная навигация (drawer)** — на 375px сайдбар скрыт без альтернативы: нет способа переключить главу, зайти в персонажей или настройки. Нужен hamburger в `PageHeader` + bottom-sheet/drawer с навигацией. Редактор на мобиле в остальном работает (~3–4 ч).
- [ ] **Мобильная версия (полная)** — адаптивный layout для всех экранов. Минимум: редактор + список глав + дэшборд. Писатели набрасывают на ходу.
- [ ] **Расширенная проверка орфографии** — TipTap-расширение поверх [LanguageTool API](https://languagetool.org/dev).
- [ ] **Версии главы (git-like rollback)** — автосохранение снимков текста с возможностью отката. Вопрос: достаточно ли undo/redo или нужна история по датам — выяснить у пользователей.
- [ ] **Scenes и иерархия внутри глав** — подразделы внутри главы.
- [ ] **Хостинг в РФ (при росте)** — Timeweb Cloud App Platform или VPS (Beget/Selectel) при жалобах на доступность или требованиях ФЗ-152.

## Продвижение — фазы выхода к аудитории

### Критерии готовности к продвижению

- [ ] Фаза 0 + Фаза 1 закрыты
- [ ] Лендинг и онбординг работают
- [ ] Есть канал обратной связи

### Фаза 0 — Ручное тестирование (до 10 июня)

Найти 5–10 настоящих авторов (не знакомых). Источники:
- ВКонтакте: группы «Авторы», «Писатели России», «Самиздат авторы»
- Telegram: чаты авторов самиздата, «Лаборатория фантастики», «Пишем книги»
- Author.Today, Литнет — авторы любительской прозы, горячая аудитория
- LiveLib — форумы авторов

Формат: *«Делаю Scrivener в браузере на русском. Ищу авторов-бета-тестеров. Бесплатно, мне нужна обратная связь, а не деньги.»*

### Фаза 1 — Первые 20–50 пользователей (июнь–июль)

- Telegram-чат «Авторская студия | бета» — место для фидбека
- Посты в тематических обсуждениях: LiveLib, ВКонтакте-группы авторов, Пикабу
- Честный тон, без рекламного голоса

### Фаза 2 — Рост до 100–300 пользователей

- Пост на Хабре / vc.ru: *«Я сделал русский Scrivener с Claude Code — что получилось»* — работает при наличии честной истории и скриншотов
- Telegram-канал с changelog: скриншоты, новый функционал, вопросы к аудитории
- Партнёрство с Author.Today — крупнейшая площадка самиздата РФ
- Платная реклама — только после скриншотов и отзывов

### Фаза 3 — Монетизация (не раньше 100–300 активных бесплатных)

| Тир | Цена | Что включает |
|---|---|---|
| Free | 0 ₽ | 1 книга, базовый редактор, ~20 персонажей, без экспорта |
| Pro | 290–390 ₽/мес или ~2 900 ₽/год | Безлимит проектов, все функции, экспорт, соавторство |
| Lifetime | 1 990–3 490 ₽ | Всё навсегда, разовая оплата |
