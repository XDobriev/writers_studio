## Приоритет 1 — UX заметок и структуры

- [ ] **Виды заметок** — оставить только Идея / Вопрос / TODO. Добавить пользовательские теги с фильтрацией.
- [ ] **Привязка заметки к главе** — при создании из редактора предлагать `chapter_id`. В списке заметок показывать «Глава N».
- [ ] **Ежедневная цель слов** — статичная в настройках книги + клик по счётчику в статус-баре открывает inline-редактирование цели.
- [ ] **Объединить «Структура» и «Доска»** в один пункт сайдбара с переключателем вида внутри страницы.
- [ ] **Переосмыслить разделы Структуры** — разграничить логику трёх видов (Список / Доска / Дерево). Добавить drag-n-drop порядка глав с автопересчётом нумерации.
- [ ] **Удалить главу** — кнопка в меню главы (⋯). Если глава не пустая — показывать подтверждение «Вы уверены?».
- [ ] **Выравнивание текста по ширине по умолчанию** — установить `text-align: justify` как дефолт в редакторе (решено: да, имитирует книжный формат).

## Продвижение и монетизация

### Критерии готовности к продвижению

- [ ] Весь путь нового пользователя пройден без подсказок (регистрация → книга → глава → сохранение → возврат)
- [ ] Нет критичных потерь данных или сломанного входа
- [ ] Есть канал обратной связи (Telegram-чат или почта) и готовность отвечать

### Фазы выхода к аудитории

**Фаза 0 — ручное тестирование (сейчас)**
- Дать попробовать 2–3 знакомым авторам без объяснений
- Собрать: что непонятно, где зависло, чего не хватает

**Фаза 1 — первые 20–50 пользователей**
- Telegram-чат «Авторская студия | бета» — место для обратной связи
- Написать в тематические обсуждения: LiveLib, ВКонтакте-группы авторов, Пикабу
- Формат: честно, без рекламного тона — «делаю инструмент, ищу авторов потестировать»

**Фаза 2 — рост до 100–300 пользователей**
- Пост на Хабре / vc.ru / Пикабу: «Я сделал русский Scrivener в браузере»
- Telegram-канал с обновлениями (changelog, скриншоты, истории пользователей)
- Платная реклама на LiveLib — только когда есть скриншоты и отзывы

**Фаза 3 — монетизация**
Не раньше 100–300 активных бесплатных пользователей.

### Модель монетизации

| Тир | Цена | Что включает |
|---|---|---|
| Free | 0 ₽ | 1 книга, базовый редактор, ~20 персонажей, без экспорта |
