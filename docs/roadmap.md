## Фаза 2 — Июнь–Июль: рост и дифференциация

Фичи, которые отличают продукт от Google Docs и дают основание платить.

### Монетизация-инфраструктура

- [ ] **ЮKassa** — основной платёжный провайдер для РФ. Поддерживает самозанятых (4% с физлиц, 6% с юрлиц, лимит 2,4 млн ₽/год). Edge Function для вебхуков ЮKassa → обновление `plan` пользователя.
- [ ] **Управление подпиской** — модалка в SettingsModal: текущий план, кнопка апгрейда, история платежей. Сейчас кнопка «Управление» disabled.
- [ ] **Lifetime deal (при запуске)** — 50–100 Lifetime за 1990 ₽ в момент публичного анонса. Платформа: Хабр / ProductHunt / Telegram-канал.

### Соавторство (ключевая фича)

Реализовывать поэтапно, не всё сразу.

- [ ] **Уровень 1 — Публичная ссылка (read-only)** — `share_token` для книги → `/share/{token}` без авторизации. Миграция: `share_token uuid` в `books`.
- [ ] **Уровень 2 — Приглашение соавтора** — таблица `book_collaborators (book_id, user_id, role: editor|viewer, invited_by, created_at)`. Владелец вводит email → pending-запись → принятие по email-ссылке. RLS: `auth.uid() = user_id OR EXISTS (SELECT 1 FROM book_collaborators WHERE book_id = ... AND user_id = auth.uid())`.
- [ ] **Уровень 3 — Real-time (после 100 платящих)** — Y.js + TipTap Collaboration extension + Supabase Realtime или Hocuspocus (Fly.io/Timeweb). TipTap v3 поддерживает Y.js нативно.

### Визуализация

- [ ] **Горизонтальная timeline** — события по `pos` из `timeline_events` в виде горизонтальной ленты.
- [ ] **Графическая карта мира** — рендер локаций по `x/y` из `locations` (canvas или SVG, drag для перемещения).

### Экспорт расширенный

- [ ] **DOCX** — через `docx.js`. Титульная страница (название, автор, жанр), оглавление, разделители глав.
- [ ] **FB2** — формат популярен в РФ (Litres, FB Reader). Структура: `<FictionBook>` + `<body>` с `<section>` на главу. Без библиотек.
- [ ] **EPUB** — через `epub-gen` или `foliant`. Метаданные, обложка, оглавление, корректные разрывы глав.

## Продвижение — фазы выхода к аудитории

### Критерии готовности к продвижению

- [ ] Юридический минимум выполнен
- [ ] Лендинг и онбординг работают
- [ ] Есть канал обратной связи (Telegram-чат или почта)

### Фаза 0 — Ручное тестирование (до 10 июня)

Найти 5–10 настоящих авторов. Источники:
- ВКонтакте: группы «Авторы», «Писатели России», «Самиздат авторы»
- Telegram: чаты авторов самиздата, «Лаборатория фантастики», «Пишем книги»
- Author.Today, Литнет — авторы любительской прозы, горячая аудитория
- LiveLib — форумы авторов

Формат: *«Делаю Scrivener в браузере на русском. Ищу авторов-бета-тестеров. Бесплатно, мне нужна обратная связь, а не деньги.»*

### Фаза 1 — Первые 20–50 пользователей (июнь–июль)

- Telegram-чат «Авторская студия | бета» — место для фидбека
- Посты в тематических обсуждениях: LiveLib, ВКонтакте-группы авторов, Пикабу
- Честный тон, без рекламного голоса

### Фаза 2 — Рост до 100–300 пользователей

- Пост на Хабре / vc.ru: *«Я сделал русский Scrivener с Claude Code — что получилось»*
- Telegram-канал с changelog: скриншоты, новый функционал, вопросы к аудитории
- Партнёрство с Author.Today — крупнейшая площадка самиздата РФ
- Платная реклама — только после отзывов

### Фаза 3 — Монетизация (не раньше 100–300 активных бесплатных)

| Тир | Цена | Что включает |
|---|---|---|
| Free | 0 ₽ | 1 книга, базовый редактор, ~20 персонажей, без экспорта |
| Pro | 290–390 ₽/мес или ~2 900 ₽/год | Безлимит проектов, все функции, экспорт, соавторство |
| Lifetime | 1 990–3 490 ₽ | Всё навсегда, разовая оплата |
