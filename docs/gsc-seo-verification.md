## 1. Что было диагностировано и исправлено (PR #73)

### Проблема в отчетах GSC (август — ноябрь 2026):
1. Число проиндексированных страниц упало с 5 до 3, а 11 страниц попали в категорию «Не проиндексировано».
2. **«Страница с переадресацией» (7 URL)**:
   - Причина: пререндер создавал поддиректории (`dist/offer/index.html`), из-за чего Nginx при обращении к `/offer` выдавал директивный 301 редирект на `/offer/`. При этом `<link rel="canonical">` внутри HTML указывал на `https://avtorstudio.com/offer` (без слэша). Возникал цикл редирект ↔ canonical.
   - Исправление: пререндер переведён на плоские файлы (`dist/offer.html`, `dist/terms.html`, и т.д.), в Nginx настроен стрип трейлинг-слэшей (`/offer/` -> `/offer` [301]), а раздача идет через `try_files $uri $uri.html @spa;`.
3. **«Вариант страницы с тегом canonical» (1 URL)**:
   - Исправлено приведением всех внутренних ссылок, карты сайта и ответов Nginx к единому каноническому виду без слэша на конце.
4. **Скрытие контента анимацией Framer Motion при пререндере**:
   - Причина: элементы с `whileInView` и `heroItemVariants` сериализовались в статический HTML с инлайн-стилем `style="opacity: 0"`.
   - Исправление: в `scripts/prerender.mjs` добавлен пошаговый скролл страницы и ожидание стабилизации анимаций (`revealAllScrollSections`), благодаря чему статический HTML отдается с полным видимым текстом.
5. **Директивы индексации**:
   - Для `/demo` добавлен HTTP-заголовок `X-Robots-Tag: noindex, nofollow` в Nginx и хук `usePageMeta` в коде страницы.
   - Из `index.html` удален ошибочный одиночный `hreflang="ru"`.
   - В `robots.txt` нормализованы правила `Disallow`.

Все изменения уже задеплоены на боевой VPS Timeweb и проверены.

## 2. Что осталось сделать (Чек-лист владельца)

### Шаг 1. Консоль VPS Timeweb — Расширение SSL-сертификата (1–2 минуты)

В веб-консоли Timeweb Cloud (или по SSH `root@72.56.232.231`) выполнить:

```bash
sudo certbot --nginx --expand -d avtorstudio.com -d www.avtorstudio.com -d api.avtorstudio.com
```

**Интерактивные ответы certbot:**
1. На вопрос «What would you like to do?» выбрать вариант:  
   `2: Renew & replace the certificate` (Обновить и заменить сертификат)
2. На вопрос о редиректах выбрать:  
   `1: No redirect` (Редирект на https и без www уже жестко прописан в нашем `nginx.conf`)

После успешного выпуска применить конфигурацию:
```bash
sudo nginx -t && sudo systemctl reload nginx
```

**Проверка результата (в любом терминале):**
```bash
curl -I https://www.avtorstudio.com/
```
Должен вернуть `HTTP/2 301` с заголовком `Location: https://avtorstudio.com/` без ошибок проверки сертификата.

### Шаг 2. Google Search Console — Валидация исправлений (3–5 минут)

Открыть панель **[Google Search Console — avtorstudio.com](https://search.google.com/search-console)**:

1. **Запуск проверки в отчётах об индексировании:**
   - В левом меню перейти в раздел **Индексирование** → **Страницы**.
   - Найти строку **«Страница с переадресацией»** (Page with redirect) → открыть и нажать кнопку **«Проверить исправление»** (Validate Fix).
   - Найти строку **«Вариант страницы с правильным каноническим тегом»** (Alternate page with proper canonical tag) → открыть и нажать кнопку **«Проверить исправление»**.
   - Статус перейдет в состояние «Проверка начата» (Pending).

2. **Ручной запрос переиндексации (Инструмент «Проверка URL» / URL Inspection):**
   В верхней строке поиска GSC поочерёдно ввести следующие адреса и нажать **«Запросить индексирование»** (Request Indexing):
   - `https://avtorstudio.com/`
   - `https://avtorstudio.com/offer`
   - `https://avtorstudio.com/terms`
   - `https://avtorstudio.com/privacy`
   - `https://avtorstudio.com/changelog`

3. **Проверка исключения технических страниц:**
   - Ввести в проверку URL: `https://avtorstudio.com/demo`
   - Нажать «Проверить страницу на сервере» (Test Live URL) → убедиться, что в блоке доступности указано: *«Индексирование запрещено тегом noindex (HTTP-заголовок X-Robots-Tag)»*.

### Шаг 3. Контроль результатов (в течение 7–14 дней)

1. **Google Search Console:**
   - Число страниц в статусе «Проиндексировано» должно вырасти до **5** (`/`, `/offer`, `/terms`, `/privacy`, `/changelog`).

   - Убедиться, что в разделе «Индексирование» → «Страницы в поиске» все 5 публичных страниц находятся в поиске.

## 3. (Опционально) Доступ разработчика/агента к VPS

Чтобы в будущем агент или разработчик мог диагностировать сервер и выполнять команды без входа в веб-панель Timeweb:
1. Добавить публичный SSH-ключ в файл `/root/.ssh/authorized_keys` на VPS.
2. Проверить вход командой: `ssh root@72.56.232.231`.
