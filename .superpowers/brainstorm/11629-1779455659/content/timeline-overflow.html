Как хронология ведёт себя при 20+ событиях?

Выбери подход, который нравится больше всего

A

Змейка (Snake)

Строки чередуют направление: →, ←, →, ← Визуально связаны стрелками на переходах. Органично для нарративных инструментов.

строка 1 →
→
Начало пути
Встреча
Битва
Мир
Предательство
Побег
Пропасть
↩ перенос
строка 2 ←
←
Замок
Союз
Осада
Магия
Финал
Конец

Плюсы

  • Визуально захватывающий
  • Нет горизонтального скролла
  • Нарративный, как книжный стрип

Минусы

  • DnD сложнее переосмыслить
  • Нестандартная UX-парадигма
  • ~2–3 дня работы
B

Многострочная лента

События переносятся на следующую строку слева направо — как текст. Каждая строка — отдельная ось. Простая и предсказуемая.

Начало
Встреча
Битва
Мир
Предательство
Побег
…
Замок
Союз
Осада
Магия
Финал

Плюсы

  • Привычная логика (слева направо)
  • DnD остаётся рабочим
  • ~1 день реализации

Минусы

  • Связь между строками неочевидна
  • Менее «нарративный» вид
C

Компакт + мини-карта

Текущая горизонтальная лента, но: карточки уже (100px вместо 168), добавляется мини-карта прокрутки снизу.

Начало
Встреча
Битва
Мир
Предат.
Побег
Замок
Союз
Осада
Магия
Финал
Конец
↔ мини-карта (синий блок = видимая область)

Плюсы

  • Минимальные изменения кода
  • DnD работает без изменений
  • 0.5–1 день

Минусы

  • Горизонтальный скролл остаётся
  • Карточки плотнее, меньше текста
